# Отправка расшифровки в Telegram через свой сервер (необязательно)

Без этого расшифровки просто лежат в папке `Документы\Расшифровки встреч`. Если у вас есть свой сервер с ботом Telegram,
программа может ещё и присылать файл в тему (топик) группы.

1. На сервере положите `tg-doc` в `~/bin/` и сделайте исполняемым: `chmod +x ~/bin/tg-doc`.
2. Создайте `~/.tg-doc.env` (права `chmod 600`):
   ```
   TELEGRAM_BOT_TOKEN=токен_бота_от_BotFather
   TELEGRAM_CHAT_ID=-100xxxxxxxxxx
   ```
   Бот должен быть участником группы и иметь право писать в тему.
3. На компьютере должен работать `ssh <имя>` без пароля (по ключу, имя из `~/.ssh/config`) и `scp`.
4. В `%LOCALAPPDATA%\MeetingRecorder\settings.json` укажите:
   ```json
   {"server": {"ssh_host": "имя_из_ssh_config", "thread_id": "номер_темы", "remote_dir": "meetings"}}
   ```
   Папка `~/meetings/` на сервере должна существовать. Токен бота остаётся на сервере и в программу не попадает.
